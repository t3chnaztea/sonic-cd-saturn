## V0.037: title screen, menu and game flow

Flow (`CD Initial Program/IPX.asm`): the program runs MDINIT and BURAMINIT, then `.GameLoop` runs the title (SCMD_TITLE) and the scene its exit code selects. There is no Sega or Sonic Team logo program in the Mega CD game (IPX.asm and the retail IPX___.MMD go from BURAMINIT straight to the title; the CD BIOS shows the Sega license screen, as the Saturn BIOS does for this disc), so the planned logo screens do not exist to port. Exit 1 starts NEW GAME (Act 1 Present from its start with the title card and a fade from black). The attract demos, RAM data manager and other scenes are outside this prototype, so their exit codes run the title again. A game over (8 seconds with no lives, `Sonic/Main.asm` oPlayerReset) fades out and returns to the title (`IPX.asm GameOver`); the end-of-prototype screen also returns to the title. Without save data Mega Drive Init sets titleFlags to %10010000, so the menu lists NEW GAME and RAM DATA; CONTINUE and the other options need saved progress, which this prototype does not write.

Title (`Title Screen/Main.asm`, `Sub.asm`, Objects, USA): `src/title.c` runs the Main CPU program one V-INT at a time (InitMD, DrawTilemaps, art loads at their VRAM addresses, the 48-frame delay, Sonic's palette fade, the Sonic turn with arm and banner, the white flash, planet, menu with arrows, copyright and TM, the MainLoop with PaletteCycle, ScrollBgBuf1/2 and the exit fade) and the Sub CPU cloud operation (GenGfxTraceTbl with 68000 MULS/DIVS semantics, 32x32 stamps on a repeated 4096x4096 map, cell-ordered image buffer, COPYIMG halves). The state keeps Mega Drive VRAM, CRAM, H-scroll and the sprite table. `tools/title_assets.py` packs the Nemesis/Kosinski data (95,340 bytes, TITLE.BIN) and requires each compressed file once in the retail TITLEM.MMD or TITLES.BIN. `src/title_view.inc` maps planes A/B to NBG0/NBG1 with cell priority and line scroll and the sprite table to VDP1 textures cut from the Mega Drive VRAM; the slave SH-2 renders each cloud image while the master continues, like the Sub CPU. The frames the retail program misses before a V-INT (67 at start, 5/1/10 for Sonic's art loads, 9 at the first image, one before each image pair, one after a menu text load) are shown as repeated pictures, so the title keeps the original 40 V-INTs per second in the menu. The title music is retail CD track 26, played once (SPX.asm SPCmd_LoadTitle), as Saturn track 11. The boss music (era 8) was ignored by `scd_audio_era` since V0.035; it plays now.

Measured presentation: VDP1 and VDP2 show a V-INT three frames after it runs (the sprite table is held one frame and VDP2 memory waits one commit). Retail row 11 of the clouds, which always shows buffer 1, keeps the previous image in cell columns 30-31 for one more frame, because the VDP is still transferring the end of COPYIMG's second half when it draws line 88; the view writes those tiles one commit late. Act 1 from NEW GAME starts with the title card, so the act gates' Right/jump route follows a longer path.
