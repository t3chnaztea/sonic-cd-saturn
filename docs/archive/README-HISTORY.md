Moved verbatim from `README.md` ("Historical build checkpoints") on 2026-10-03. History, not live documentation.

**V0.037 boots into the original title screen and menu; the game flow runs from the title through Palmtree Panic and back; all 24 functional gates pass.** The title is the Mega CD program (`Title Screen/Main.asm` and `Sub.asm`) ported to native C (`src/title.c`): Sonic's fade and turn, the white flash, the emblem, planet, water cycle and line scroll, and the rotating cloud plane rendered like the Sub CPU's graphics chip on the slave SH-2. Press Start to open the menu and A, B or C to choose NEW GAME, which starts Act 1 with its title card. A fresh Mega CD lists NEW GAME and RAM DATA; RAM DATA and the time-out demo are not ported, so they return to the title. A game over and the end-of-prototype screen also return to the title. A retail oracle runs the original disc in the pinned Sega CD core (`tools/title_retail.py`). On the host the native program equals retail after every V-INT of a NEW GAME route and a time-out route (1,970 V-INTs). In Beetle Saturn the same NEW GAME route matches all 823 V-INTs, including the frames the original misses, and 1,196 of 1,196 shown pictures equal the retail pictures. The Mega CD game has no Sega or Sonic Team logo screens; the BIOS license screen comes first on both machines. The title music is the retail title track, and the boss music, silent since V0.035, now plays. Hold Start and Right and press C for a game over fixture. One Beetle Saturn run now goes from NEW GAME through Acts 1 to 3 (scores 2,800, 7,200 and 18,400; the unchanged Act 1 route takes a longer path behind the title card) to the end screen and back to the title, with exact host replays. Heap capacity before allocations is 589,720 bytes. Release preservation uses `build/hardware-v0.037/`. Act 2/3 routes in other eras, saving, and hardware acceptance remain unfinished.
