Why does this preview need a private bundle?

The current native build converts game data from local sources. Its delta bundle contains some of that data. It must not be published. A public patch needs an asset extraction route that supplies those bytes from the user's own files.

This preview proves the local browser flow against the accepted release. It does not distribute a playable image, a BIOS, music or game art. The site has no analytics, remote fonts or upload endpoint.
